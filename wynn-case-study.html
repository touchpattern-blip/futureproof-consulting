The situation

A rig that had to run without the people who built it

Thirty-eight ADC ConTour winches on one control network, moving drape and scenic elements for a Wynn destination property. Technical direction and commissioning, delivered through Rose Brand.

The system was test-built and commissioned in full at the manufacturer's facility. Then it was struck, crated, and shipped to the destination site, where a different crew would put it back together months later without the people who had just spent weeks learning its behavior.

These are overhead lifting winches working above an occupied space. There is no partial credit on a rig like that. It either comes up correctly on the other end or it does not come up.

So the job was two jobs. Commission the system, and build the tooling that lets someone else commission it again.

What I built

Three artifacts

01

An interactive system reference the crew could actually use

One HTML file. No server, no install, no network. It opens on any laptop, tablet, or phone that happens to be in the room, including a laptop opened next to a shipping container.

  • A live plan view of the rig with selectable positions, layered so you can turn structure, hardware, and data on and off independently.
  • Searchable address and equipment tables, so nobody has to hunt through a PDF to answer one question.
  • A 7-phase, 64-step assembly and commissioning checklist that saves progress in the browser. A crew can stop mid-phase, close the lid, and pick up where they left off.
  • Full equipment specifications in the same file, so the reference and the data never drift apart.

A printed copy went into the shipping container with the hardware, because the file is only useful if someone knows it exists.

02

A six-sheet electrical drawing set

The system started with its power, data, and control information crowded onto one dense sheet. I rebuilt it as a proper set, E000 through E005, organized around how someone reads a drawing on site rather than how the data was collected.

  • E000 is a cover and index: system summary, line key, drawing index, and an explicit read order.
  • E001 establishes the head end once. It is not repeated on any other sheet.
  • E002 through E005 each take one section of the rig and pick up at its own feed. An electrician standing under one part of the system reads one sheet.

Drawn as HTML and SVG at full 17x11 sheet size, with revision block, title block, and drawing numbers, then printed to PDF. It reads like a drawing set because contractors do not have time to learn a new document format on a job site.

A separate standalone power drop drawing was issued to the venue's electrical contractor, so the trade doing the rough-in got exactly the sheet it needed and nothing else.

03

Startup documentation, and the vendor fault report

Two guides came out of the commissioning. A startup guide that walks one winch from the box to a saved position in eight steps, written for a reader with no prior experience on the platform. And a deeper field reference covering calibration, homing, scene building, and the failure modes we hit, with the fix for each one.

The third document came out of a fault. Partway through the build, a subset of the winches would not home. I worked it by elimination and ruled out seek direction, torque, feedback direction, and home method. Then I diffed a failing axis against a working axis field by field. Every value matched. The only difference was a single direction-inversion flag.

That became a written engineering note listing four reproducible faults at the firmware level: home not retained across a restart, inverted-mount axes faulting once travel limits are set, unreliable jog from the pendant, and reversed trip indicators on the limits screen. The manufacturer's own representative had not seen the homing fault before.

The note went to the manufacturer's product team as a fix request, with the acceptance criteria written out, including regression testing across the whole system and a way to lock a known-good version so a later update cannot silently change an approved show configuration. On the same pass I pushed the manufacturer to generate and hand over full backup and clone files for every axis, which the department had never held before and now does.

The point

The tooling is the part that survives

The rig was never the deliverable. The deliverable was everything that let a stranger bring it up correctly months later, with the original crew unreachable. Tooling that holds its own state, documents organized the way the work is actually done, and faults written down precisely enough for a vendor engineer to reproduce them.

I do the same thing now with AI systems. Local-first orchestration across four machines, running my own operations daily, with the architecture written down so it outlives any one session or any one model. That is published at futureproofav.com/whitepaper.
