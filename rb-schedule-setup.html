RB Schedule → iPhone Calendar

One-time build, about 15 minutes. After this it runs itself every morning and your assigned schedule shows up in your native iPhone calendar. Everything below stays inside Microsoft's cloud; nothing installs on the laptop.

Four stages: 1 save the script · 2 make the calendar · 3 build the flow · 4 publish + subscribe.

Stage 1 — Save the script

  1. Open futureproofav.com/rb-schedule.txt. Click into it, Ctrl+A, Ctrl+C.
  2. In Excel (the RBW schedule open): Automate tab → New Script.
  3. Select the template code in the editor (Ctrl+A), delete it, then Ctrl+V to paste this in.
  4. Click Save. Rename the script to RB Schedule Sync (click the script name at the top to rename).
  5. Optional sanity check: click Run. It should complete with no error (it returns your rows to nowhere for now).

Stage 2 — Make the calendar

  1. Open Outlook on the web → Calendar.
  2. Left pane: Add calendar → Create blank calendar.
  3. Name it exactly RB Schedule → Save.

Stage 3 — Build the flow

  1. Go to flow.microsoft.com → Create → Scheduled cloud flow.
  2. Name it RB Schedule to Calendar. Set Repeat every 1 Day. Click Create.
  3. (Optional) click the Recurrence step and set a preferred time, e.g. 05:30, Time zone Pacific.
  4. + New step → search Excel Online (Business) → action Run script.
    • Location: OneDrive for Business (or the SharePoint site where the schedule file lives)
    • Document Library / File: pick the RBW schedule workbook
    • Script: RB Schedule Sync
  5. + New step → Office 365 Outlook → Get events (V4).
    • Calendar Id: RB Schedule
    • Open Show advanced options → set Top Count to 500
  6. + New step → Apply to each. In "select an output," pick value (from Get events). Inside it, Add an action → Office 365 Outlook → Delete event (V4).
    • Calendar Id: RB Schedule
    • Event: pick Event id (from the loop item)
    This clears the calendar so each run is a clean mirror. It only ever touches the dedicated RB Schedule calendar.
  7. + New step (after that loop, not inside it) → Apply to each. In "select an output," pick result (from Run script). Inside it, Add an action → Office 365 Outlook → Create event (V4). Map the fields:

  1. Save. Then click Test → Manually → Run to fire it once now.
Check: open the RB Schedule calendar in Outlook. You should see your assigned jobs populate (timed ones at their times, everything else all-day, multi-day trips as spans).

Stage 4 — Publish + subscribe your iPhone

  1. Outlook web → Settings (gear) → search publish (or Calendar → Shared calendars).
  2. Under Publish a calendar: pick RB Schedule, permission Can view all details, click Publish.
  3. It gives two links. Copy the ICS one (not HTML).
  4. On the iPhone: Settings → Calendar → Accounts → Add Account → Other → Add Subscribed Calendar → paste the ICS link → Next → Save.
How it behaves.
  • What syncs: every row where your Gio column has hours (site visits, installs, prep, travel, PTO). Other people's site visits are left out.
  • Reschedules and edits in the sheet just move or update the event on the next run. No duplicates, ever, because each run rebuilds the calendar from scratch.
  • Times: rows with a clean time like 10:00am become 2-hour blocks; anything without a parseable time is all-day; date ranges are multi-day all-day spans.
  • Refresh on the phone: iOS pulls subscribed calendars on the schedule under Settings → Calendar → Accounts → Fetch New Data. Set to hourly if you want it snappier.
If the flow errors. "Script not found" means the script did not save into your OneDrive Office Scripts; reopen Automate, confirm RB Schedule Sync is listed, re-save. If Create event rejects a date, confirm Start/End are mapped to start/end and Time zone is set.
