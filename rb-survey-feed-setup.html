RB Site Survey Feed — Run & Send

This pulls your pending jobs off the schedule sheet into the survey app's "Load from pending order" dropdown, with customer IDs and contacts. One run gives real data now; automating the refresh is a later step. The script only reads the sheet, it never changes it.

Two stages: 1 save + run the script · 2 send me the output. About 3 minutes.

Stage 1 — Save & run the script

  1. Open futureproofav.com/rb-orders.txt. Click into it, Ctrl+A, Ctrl+C.
  2. In Excel with the RBW schedule open: Automate tab → New Script.
  3. In the code editor, select the template code (Ctrl+A), delete it, then Ctrl+V to paste this in.
  4. Click Save. Click the script name at the top and rename it to RB Site Survey Feed.
  5. Click Run. It finishes with no error and prints one long line in the output/console pane at the bottom, starting with:
    {"generated":"2026-07-27","orders":[ ... ]}

Stage 2 — Send me the output

  1. In the output pane, select that whole JSON line (starts with {, ends with }), Ctrl+C.
  2. Open drop.hyperchrist.com (PIN 47732).
  3. Paste the JSON into the note box, label it orders, hit Send.
That's it. I publish it as the live feed and your dropdown fills with real customer IDs and contacts. No app changes on your end.

What happens after

  1. Now: the dropdown is live-accurate from this one run.
  2. Optional auto-refresh: generate a futureproofav Gmail app password (Google Account → Security → App passwords) and drop it to me. Then I wire a scheduled flow (using this same RB Site Survey Feed script) so the feed republishes on its own, and hand you a short flow-build guide. Until then, re-running Stage 1 whenever you want fresh jobs is the manual refresh.
If Run shows nothing in the output pane, make sure you're on the RBW workbook and the tab is named RBW 2026. If it prints "Sheet not found" it will list the tab names instead, send me that line and I'll adjust.
